# LimeLauncher

Лаунчер Minecraft: Java Edition для Android с управлением в стиле Bedrock и упором на производительность. Ядро написано на Rust.

## Что уже есть

- **Управление:** сенсорный обзор с настраиваемой чувствительностью (общая и по вертикали), ускорение, сглаживание, мёртвая зона, инверсия оси Y. Дробные доли пикселя не теряются, поэтому низкая чувствительность остаётся плавной. Раскладка экранных кнопок в стиле Bedrock (прыжок, приседание, атака, инвентарь, чат и т. д.).
- **Производительность:** профили `Low / Balanced / High` по объёму ОЗУ. Под телефоны с 3 ГБ автоматически берётся небольшая память под игру, лёгкий сборщик мусора (Serial GC), малая дальность прорисовки.
- **Версии:** разбор манифестов Mojang, фильтр библиотек по правилам ОС, сборка команды запуска (современный и старый форматы).
- **Загрузка:** параллельная, с повторными попытками, проверкой SHA-1 и пропуском уже скачанных файлов; запись атомарная.
- **Приложение:** песочница управления: двигаете пальцем и сразу видите итоговое движение мыши при выбранной чувствительности.
- **Сборка:** релизный профиль с `lto = "fat"`, `opt-level = 3`, `panic = "abort"`, R8 для APK.

## Чего ещё нет (следующие шаги)

1. Запуск самой игры: нужен JRE для Android (arm64) и слой графики (OpenGL ES ⇄ OpenGL). Планируется подключить готовые открытые компоненты.
2. Вход в аккаунт и загрузка версий из интерфейса.
3. Экранные кнопки поверх игры и редактор раскладки.

## Сборка APK

Ничего ставить не нужно: GitHub Actions собирает проект сам. Откройте вкладку **Actions → Build APK**, дождитесь зелёной галочки и скачайте `LimeLauncher-apk` из раздела Artifacts.

Локально (если есть ПК): `cargo test -p lime-core`.

## Полный лаунчер с Java (Minecraft 1.18.2 и другие)

Рабочий запуск игры обеспечивает открытый проект [PojavLauncher](https://github.com/TeamPojavLauncher/PojavLauncher) (лицензия LGPL-3.0): в нём уже есть Java 8/17/21 для arm64, слой графики и поддержка почти всех версий. Workflow **Build LimeLauncher (full, with Java)** скачивает его зафиксированную версию, накладывает наши изменения (`scripts/apply-lime.sh`, патчи из `patches/`) и собирает APK `LimeLauncher-full`. Для 1.18.2 нужна Java 17, она входит в сборку.

Огромное спасибо авторам PojavLauncher, MojoLauncher, GL4ES и LWJGL. Наши изменения распространяются в открытом виде в этом репозитории.

## Структура

- `core/` — ядро на Rust (`controls`, `settings`, `manifest`, `launch`, `download`, мост JNI)
- `android/` — приложение для Android (Kotlin)
- `.github/workflows/build.yml` — тесты и сборка APK
